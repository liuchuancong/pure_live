# fixtures

跨包共享的**录制样本**:确定性测试的输入,不是运行时代码。

- 放这里的前提:同一份样本被**两个及以上**的包使用(例如多个 provider 共用的 TVBox `jar` 骨架、通用 m3u/EPG 解析样本、HTTP 错误响应)。
- 单一 provider 专属的响应样本放在该包内 `fixtures/`(脚手架为 providers 层生成的目录),与它的契约测试同生命周期。
- 样本必须是**去凭据**后的录制结果:删除 Cookie、token、用户标识;保留结构与边界字段。
- 文件名带来源与采集日期,例如 `bilibili_room_init_2026-10-08.json`;更新样本要在同一次提交里说明上游变化。

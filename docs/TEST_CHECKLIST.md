# Pure Live 双端功能测试清单

覆盖用户在 Android（A）与 Windows（W）上能看到、能操作、能感知到的全部功能。每项写明检查点与验证方式，按 [验收流程](ACCEPTANCE_FLOW.md) 分级执行。

验证方式：**U** 单元/组件测试（`flutter test`）· **P** 全平台探针（`tool/probes/all_sites_playback_probe_test.dart`）· **D** 真机（Android 走设备租约；Windows 为本机 GUI）。

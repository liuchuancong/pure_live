# 局域网同步 · 两台设备手工验证清单

> 适用：两台设备安装了带局域网同步的 PureLive（Windows/Android 等），
> 连接**同一网络**（同一 Wi-Fi/路由器，未开 AP 隔离）。
> 建议准备：两台设备都能看到日志页（设置 → 日志），便于排障。

## 0. 准备

- [ ] 两台设备都在 **设置 → 备份与同步 → 局域网同步** 打开「启用局域网同步」。
- [ ] 两台设备的「本机名称」改成可区分的名字（如 Desktop / Phone）。
- [ ] 双方各自的「附近设备」列表里能看到对方（名称 + 平台）。
      - 看不到：确认同一网段；Windows 检查防火墙是否放行 pure_live.exe
        （首次监听会弹窗，选「允许」）；路由器是否开了 AP 隔离/访客网络；
        VPN 虚拟网卡可能把流量带偏，可暂时断开。
- [ ] （可选）记录双方「本机证书指纹」前 12 位，配对后核对。

## 1. 配对

- [ ] A 点对 B 的「配对」→ B 弹出请求，**两台屏幕显示同一个 6 位数字**。
- [ ] 双方点「数字一致，确认」→ 双方都提示「已配对」。
- [ ] 双方「已配对设备」列表出现对方，指纹前 12 位与本机记录一致。
- 反向：B 对 A 发起同样成功（两台都可作为发起方）。
- 码不一致：任一方点「不一致，拒绝」→ 双方均提示已拒绝，无残留。
- 过期：发起后 3 分钟不确认 → 提示已过期，可重新发起。
- 连续错码：多次输错/拒绝后，发起方被限流提示等待（预期行为）。

## 2. 同步

- [ ] A 关注 2 个直播间 → 双方点「立即同步」→ B 出现同样 2 个关注。
- [ ] B 关注 1 个 → 同步 → A 出现（双向）。
- [ ] A 取消关注其一 → 同步 → B 同步消失（删除传播，不复活）。
- [ ] 什么都不改再点同步 → 无重复条目产生。
- [ ] A 改名某关注的显示标题？——首期收藏同步以整条收藏为单位，
      刷新即可更新；跳过此项亦可。

## 3. 冲突

- [ ] 断开 B 的网络（或关 B 的同步开关），A、B 分别对**同一条**收藏做不同
      操作（如 A 修改后 B 也修改——收藏无编辑场景时可跳过；用 删除 vs 保留
      亦可触发）→ 恢复后同步 → 不出现静默覆盖：双方按
      「冲突时保留」策略收敛，或 UI 出现冲突待处理。

## 4. 撤销与拒绝

- [ ] A 撤销 B → B 再点立即同步 → 失败（未配对）。
- [ ] 撤销后重新配对 → 一切恢复正常。
- [ ] 撤销后 B 的旧数据不会在 A 上"复活"（B 端残留变更被拒收）。

## 5. 稳定性

- [ ] 同步中关掉 B 的应用 → 重开 → 同步 → 数据完整、无重复。
- [ ] 传输中断网（Wi-Fi 开关）→ 恢复后自动补齐（自动同步去抖 3 秒）。
- [ ] Windows 防火墙：首次启动监听时允许访问；拒绝后在本机防火墙设置中
      手工放行再测发现。
- [ ] 日志抽查（设置 → 日志，过滤 lan_sync）：应有 sync started/finished、
      batch applied、conflict detected 等行；不应出现配对码、密钥、
      收藏 payload 内容。

## 6. 平台差异备注

- iOS：首次使用会弹「本地网络」权限，需允许；后台不保证监听（回前台即恢复）。
- Android TV：遥控器操作设置页；同样仅前台保证。
- Windows：多网卡/VPN 时发现可能走错网卡，重新开关同步可恢复。

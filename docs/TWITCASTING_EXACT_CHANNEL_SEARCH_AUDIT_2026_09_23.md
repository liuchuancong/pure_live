# TwitCasting 频道根链接精确查询（2026-09-23）

## 合同与实现

TwitCasting [官方帮助](https://www.tp.twitcasting.tv/helpcenter.php?pid=INDEX_HELP_LIVE)说明直播 URL 固定为频道根路径；录像另由归档入口提供。此前搜索页只查询官网当前直播文本区块，粘贴根频道链接时会把完整 URL 当关键词，无法找回未开播频道。

现在原生搜索区分输入：普通关键词继续走官网当前直播窗口；精确 `twitcasting.tv/{channel}` 根链接走频道详情与当前 `streamserver.php` 状态，返回稳定频道卡片（可含未开播）。搜索只读取元数据，不解析 HLS；播放/录制进房后才按既有合同取流。不存在的频道返回空结果；访问受限、挑战和网络异常继续保留错误。第二页与电影/归档链接不被误当当前频道直播。搜索能力标记由 `liveOnly` 调整为 `liveAndOffline`，仍只对精确根链接承诺未开播结果；关键词搜索仍限当前直播。

## 回归

先新增根链接离线回归，旧实现以 schema 错误失败；实现后覆盖离线、开播但旧媒体无效、404、取消、根路径与 movie 路径区分。最终 TwitCasting 适配器 **38/38**，搜索能力与 Widget 三文件联合回归 **121/121**，定向 Analyze 无诊断。本批为源码级验证，Android/Windows 原生输入与播放留给后续候选。

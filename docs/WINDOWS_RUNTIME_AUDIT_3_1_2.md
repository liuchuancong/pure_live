## 刷新率与设置持久化

1. 通用设置实际显示 `3840 × 2400 · 200 Hz（最高 200 Hz）`，当前与最高刷新率没有被错误截断为 60 Hz。
2. “界面刷新率”对话框完整显示三档：
   - 省电：主画面弹幕上限 60 FPS，小窗弹幕上限 30 FPS；
   - 均衡：交互期间使用最高刷新率，交互结束交还系统；
   - 最高：前台界面跟随设备/显示器上限，自动弹幕同档联动。
3. 省电 → 均衡 → 最高三次切换均在关闭对话框后即时更新当前设置说明，未要求重启。
4. 将模式设为均衡后，强制结束隔离测试进程，再使用相同 instance id 冷启动；通用设置仍显示均衡，证明持久化生效。
5. 测试结束前已恢复省电默认，辅助功能树再次报告 `省电（默认） · 200 / 200 Hz`。

# 媒体预览页方案（下载 · 录制共用语法，按模块分开入口）

需求（2026-11-01，用户）：每个支持下载/录制的模块都要有**预览视频的页面**；UI 参考 Windows Media Player——主区播放、右侧列表切换条目、带弹幕设置；兼容移动端；各模块分开做。

## 审计结论（决定了怎么"分开做"）

- 现在只有 `features/settings/pages/local_media_page.dart` 里的 `_LocalMediaPreviewPage`：黑底 + 标题栏 + `WallpaperVideoPlayer`，**没有列表、没有弹幕、没有自己的控制条**（播放器自带最简控制）。VOD 下载、红果下载、本地媒体页都调它。
- `WallpaperVideoPlayer` 已有 `overlay`（画面之上、控制之下的覆盖层）与播放/暂停/拖动/静音/时长基础设施，可直接承载弹幕层。
- 弹幕源：直播录制写同名 `.xml`（及用户选的其它格式）；**B站视频下载也会写 `.xml`**（`vod_downloads.dart` 的 `writeDanmakuFiles`）；红果下载与音乐下载没有弹幕文件。
- 录制存储是共享的：直播录制与 **IPTV 录制**都写进 `recordings` 任务库（IPTV 的 id 是 `iptv:<channelId>`），所以 IPTV 的"录制预览"不需要另一份数据源，只是同一个列表按平台过滤。
- 音乐下载是音频，没有画面：预览页用同一套"列表 + 舞台"骨架，舞台改为封面/频谱，控制条沿用音频播放。

所以"分开做"落在**入口与列表来源**上，共用一个预览页骨架（标准 §12.4：共享叶子，不共享树）。五个入口各自组装自己的条目与能力，不复制五份播放器。

## 共享页：`MediaPreviewPage`（WMP 语法）

布局（桌面宽窗，`≥ 900`）：

```
┌───────────────────────────────────────────────┬──────────────────┐
│ 标题（条目标题 · 来源 · 时长/大小）             │ 列表头：n 项 · 来源 │
│                                               │ ┌──────────────┐ │
│                舞台（video 或封面）            │ │ ▶ 当前条目     │ │
│          弹幕层（overlay，可关）               │ │   副标题·时长  │ │
│                                               │ ├──────────────┤ │
│                                               │ │   其他条目     │ │
│ 控制条：播放 · 进度 · 时间 · 音量 · 弹幕 · 设置  │ │   …           │ │
└───────────────────────────────────────────────┴──────────────────┘
```

- 顶部：返回 + 标题（当前条目）+ 来源徽标（录制/下载）+ 右侧「⋮」（打开文件夹、删除、重新合并/重试、统计、截屏——按能力出现）。
- 舞台：`WallpaperVideoPlayer(uri: file, overlay: 弹幕层)`；弹幕层用 `BarrageController` + `FlameBarrageWidget`，条目有同名 sidecar 才出现（P2 按 `xml → json → txt` 找可读格式，ASS/SRT 只给别人播放，本页不解析）。
- 控制条（自绘，WMP 风格常显）：播放/暂停、进度（可拖动；本地文件有真实时长）、`mm:ss / mm:ss`、音量、弹幕开关、**弹幕设置**（打开右侧面板）、全屏、PiP（能力位）。
- 右侧列表：当前条目高亮并自动滚到位；行 = 序号/缩略图 + 标题 + 副标题（来源 · 时长 · 大小）+ 行尾 ⋮（播放、打开文件夹、删除文件）。列表头有「共 n 项」与排序（最近在前/名称）。宽度可拖、可折叠（`≥900` 才常显）。
- 弹幕设置面板（覆盖在列表位置或右侧抽屉）：显示开关、字号、透明度、速度、密度、区域、描边、屏蔽规则入口（跳设置页）；改动即时作用于本页弹幕层，并沿用既有 `danmakuStyleProvider` 等设置（不新增偏好键）。
- 播放列表的来源与顺序由各模块给；本页只负责"上一项/下一项"、播完自动下一项（可关）。

布局档位：

- `≥900`：舞台 + 右侧列表常显。
- `600–900`：列表折叠为右侧抽屉，控制条常显。
- `<600`（手机）：舞台占上半，标题条 + 控制条在下，列表为底部抽屉（点「列表」或上滑），弹幕设置为全宽底部面板。竖屏全屏走系统方向。

状态：文件缺失（列表标灰 + 原因，播放时给"文件不在了"的状态卡）、无弹幕（开关置灰并说明"这条没有弹幕文件"）、解码失败（重试 + 打开文件夹）、空列表（不该发生：入口只在有条目时出现）。

## 模块入口（分开做，共用上面的页）

| 模块 | 入口 | 列表来源 | 弹幕 | 备注 |
| --- | --- | --- | --- | --- |
| 直播录制 | 录制中心卡片菜单「内置播放器预览」/「播放录像」 | `recordings` 任务库中已结束、且 `filePath` 里能解析出可播放文件的条目（优先 MP4，否则最大分段） | `.xml` 同名 sidecar（P2 接入） | 条目按需解析文件，录制中/合并中不进列表；「播放录像」保留为系统播放器出口 |
| IPTV 录制 | IPTV 播放页录制菜单「查看录像」→ 预览页（列表过滤 `iptv:`） | 同一个 `recordings` 库，`platform == iptv` | 无 | 与录制中心共享数据，不复制 |
| B站视频下载 | 下载管理行「预览」/详情页 | `vod` 下载任务中已完成且文件存在者 | `.xml` 同名 sidecar（下载时已写） | 失败/未完成条目不进列表 |
| 红果下载 | 下载行「预览」 | `hongguo` 下载任务已完成者 | 无 | 现有 `showLocalMediaPreview` 升级为该页 |
| 音乐下载 | 下载行「播放」 | `music` 下载任务已完成者 | 无 | 舞台为封面/频谱，控制条同音频；或直接跳音乐播放页并保留列表 |

范围外：不做播放器内核切换（预览固定用应用的 media_core 内核）；不新增依赖；不做转码/剪辑；不改 `F:/media_core`。

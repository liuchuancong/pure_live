## 根因与设计调整

此前手机横屏的“清晰度与播放线路”面板把画质区和线路区固定分配为 `4:3`。这一比例与真实选项数量无关：四个画质在三列网格中只占两行，却仍然拿走过高区域，形成大片空白；线路较多时，下方反而被裁切。

本轮改为内容驱动布局：

1. 根据面板宽度与实际选项数量共同决定网格列数。
2. 四项在三列可用宽度下优先使用 `2×2`，五至六项使用三列，窄屏自动退化为两列或一列。
3. 画质区高度由“标题 + 实际行数 + 间距 + 内边距”计算，不再占用固定比例。
4. 线路区使用剩余高度，并在小视口中获得最低可操作空间。
5. 画质区最多展示三行，极多选项在区内滚动，避免挤压线路区。

## 交互与视觉

- 画质与线路选中项共用一致的状态色、强调边框和勾选图标。
- 标题区继续显示当前画质与线路，选项区负责快速选择，信息层级更加清楚。
- 桌面大视口仍保持画质/线路左右并排，不受手机横屏纵向策略影响。

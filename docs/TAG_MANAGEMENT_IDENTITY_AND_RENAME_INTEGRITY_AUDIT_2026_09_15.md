## 状态合同

1. 每个新建标签的 ID 在当前集合中唯一，不依赖系统时钟必须前进。
2. 加载旧数据时保留重复 ID 的第一项；后续重复项和空 ID 获得新身份，顺序重排为连续的 `0..n-1`。
3. 启动修复会写回标签存储，下一次启动继续使用同一组已修复身份。
4. 仅大小写或外围空白变化属于对当前标签的合法改名；与其他标签不区分大小写的重名继续失败。
5. 改名失败不改变原名称或说明；成功后编辑弹窗正常关闭。
6. 房间映射中的旧重复 ID 继续归属于按现有顺序保留该 ID 的第一项，避免把旧映射静默转给后续碰撞项。

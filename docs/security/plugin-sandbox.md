# Plugin Sandbox

> JS 插件的隔离执行环境(fjs ^3.3.2,Rust + QuickJS)。

## 边界

| 维度 | 策略 |
|---|---|
| 执行 | 每插件独立 Runtime 实例,全局状态不共享 |
| 文件 | 无文件系统访问 |
| 网络 | 仅 PluginNetwork(白名单域/超时/响应大小上限/并发限) |
| 存储 | 仅本插件命名空间 kv(配额限制) |
| 原生通道 | 禁止;一切宿主能力经 HostBridge 白名单 API |
| 时间 | 执行超时上限;超时 → 插件 degraded |

## 失败处理

异常捕获在沙箱内上报宿主;连续失败自动禁用并通知;禁用不影响其他插件与主 App。

## 限制说明

JS 无法做到的事(复杂签名、protobuf)→ 该源应实现为 Native 插件;生态分层本身就是安全设计。

# EPG(电子节目单)

## 格式

XMLTV 为标准格式;支持按 `tvg-id`/`tvg-name` 与频道匹配(多策略:精确 id → 规范化名称模糊匹配,结果记忆)。

## 模型

```text
Program: 标题/简介/起止时间/分类
EpgEvent: 当前与接下来节目;时间轴对齐本地时区
```

## 功能

- 频道详情页:当日节目单 + 当前播放进度高亮。
- "看到节目中间"进入 → 从节目开头看(直播语义内 seek)。
- EPG 数据缓存(cache 包 epg 命名空间),定期刷新,失败用旧数据。
- 节目提醒(开播通知)为远期能力(notification 权限)。

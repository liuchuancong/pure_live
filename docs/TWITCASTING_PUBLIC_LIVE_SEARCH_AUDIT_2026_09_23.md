# TwitCasting 官网当前直播关键词搜索（2026-09-23）

## 生产来源与范围

- 官网[公开搜索页](https://search.twitcasting.tv/search/text/t?hl=en)把 Premium、当前直播、录像和用户分成不同区块。匿名读取 `artist`、`music` 与 `t` 三种关键词，HTML 响应分别约 239 KiB、249 KiB、416 KiB；当前直播区块分别为 1、6、50 条。`t` 页的计数为 `Live(50+)`，当前 HTML 恰好有 50 行，因此最多只承诺这个可见窗口，不声明全站分页。
- 直播区块各行有当前 `data-status=live` 标记、可播放标记、`/频道/movie/场次` 链接，以及主播根频道链接。搜索页的直播卡片没有已核实的并发观看人数；界面维持未知，避免把评论数、录像累计观看或电影 ID 当成在线人数。
- 空关键词探针页面仍保留直播区块但 `Live(0)`；挑战页或结构不符按解析错误处理，不伪装成空搜索结果。

## 源码合同

- `TwitcastingApi.searchLives()` 使用官网公开文本搜索页，限制关键词和页码，在最多 50 行的实际窗口内切片。只读取当前直播区块，忽略录像、Premium 和用户区块；验证直播标记、可播放标记、频道与场次链接身份，卡片使用稳定根频道 ID。
- `TwitcastingSite` 接入可取消原生搜索，能力说明标为“当前直播”，保留原网页搜索入口。搜索页不下载媒体、不代替点入房间时的详情/HLS核验。
- 电影/归档链接仍不映射为当前直播；用户档案关键词搜索目前仍交由官网网页搜索入口。此前公开热门 60 条窗口与目录人数口径保持原样。

## 验证边界

四文件定向回归 **109/109**，覆盖关键词编码、直播区块限定、50 条窗口与页边界、频道身份、畸形 HTML、取消及搜索页能力展示；定向 Analyze 无诊断。另以本轮四份官网 HTML 快照运行当前解析器 **1/1**：`artist` 1 条、`music` 6 条、`t` 首页 20 条/第三页 10 条、无匹配 0 条。探针临时测试文件已移除，原始 HTML 留在忽略目录 `local-artifacts/reference/`，不会进入仓库。Android/Windows 新候选的输入、点击、播放与返回效果归入集中原生验收。

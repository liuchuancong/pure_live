# 上游问题审计（2026-08-23）

审计范围：上游 `liuchuancong/pure_live` 最近两日新增问题，以及仍与当前维护分支稳定性相关的公开问题。代码基线真实合并至 `c3ae29bb`；本轮只更新维护仓库，不向上游创建 Pull Request。

## 结论表

|---|---|---|
| #765 Windows 小窗不记忆位置/大小、希望星标置顶 | 每次进入都重新计算主屏右下角固定矩形；窗口监听还会把小窗尺寸短暂写入主窗口尺寸设置。上游后续实现只按显示器保存坐标、未保存用户调整后的尺寸，并与现有全局窗口监听重复。星标属于新增排序能力，并非现有状态损坏 | 合并为单一路径：独立持久化小窗宽高与坐标，移动/缩放后去抖保存，增加记忆开关与重置入口；恢复时按原显示器工作区校正，显示器移除后回到应用所在屏；小窗与主窗口尺寸分开更新。特别关注继续使用现有长按标签分组，本稳定版不擅自改变“全部”页的热度/在线人数排序 |

| #770 iOS 自编译仅 IJK 有画面且低帧 | iOS 新安装仍沿用 MPV 默认值；原生层未向统一刷新率服务回报 ProMotion 上限 | iOS 新配置默认 IJK，已有显式选择不迁移；补齐显示模式通道并保留 `CADisableMinimumFrameDurationOnPhone` |
| #771 多文件字体、弹幕字体、SC 与强制销毁黑屏 | 下载器写入 `fonts/`，管理页曾读取 `fontsDir/`；选择文件未持久化/冷启动注册；SC 页未直接观察 RxList；非 Exo 纹理等待自身尺寸才挂载，形成初始化环 | 统一字体目录和所选文件持久化，主字体/弹幕字体冷启动注册；SC 实时快照与房间代次；原生纹理先挂载、再用真实尺寸更新布局 |

## 醒目留言边界

实时 WebSocket 醒目留言已经进入统一消息列表并自动过期。斗鱼“进入直播间前已经发送且仍有效”的历史醒目留言目前适配器返回空集合；该部分取决于平台可稳定复现的历史接口。本轮重点保证进入后的实时消息、页面即时刷新、去重、过期和切房隔离。

## 验证映射

- 字体：目录一致性单元测试、冷启动持久字段、下载后多文件选择流程。
- 关注：复合房间身份、外部收藏变更和链接详情补全后的响应式状态。
- 关注刷新：真实纵向拖动触发与动画、短列表可刷新、启动未知态分桶、规范房间号回包仍合并到原收藏身份、严格平台刷新能力。
- 播放器：初始化先挂载、画面适配不重开数据源、切房异步代次。
- SC/列表：RxList 实时快照、房间代次、首尾有界滚动。
- 性能：图片解码宽度有界、缓存不在卡片首挂载时驱逐、播放器/直播控制器显式释放。
- Windows 小窗：同屏恢复、跨屏恢复、离屏回退与设置备份字段单元测试。

Issue #765 的小窗几何缺陷已落地修复；其“星标置顶”部分保留为产品排序需求，避免在稳定版中绕过用户现有标签和人数排序规则。

最终门禁与产物状态见 [v2.6.0 阶段稳定版](STAGE_UPDATE_2_6_0.md)。

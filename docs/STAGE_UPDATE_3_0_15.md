# Pure Live v3.0.15 阶段更新

- 版本：`3.0.15+4103`
- 目标：Android `arm64-v8a` Release
- 来源：当前维护分支；本轮没有合并上游
- 问题来源：`fork-regression`（v3.0.14 播放器恢复设计）

## 变更

- 原生播放状态不再依赖 URL 精确匹配或可选 mpv 首帧属性。
- 来源 open 完成后接收当前代次的播放、缓冲和成对尺寸事件。
- 移除两层推测式就绪超时，避免正常慢流被自动重开。
- 增加重定向 URL、无 path、无首帧属性、无推测重开和竖屏尺寸链路回归。
- 构建与验证记录由 `local-artifacts/build-records/` 和 Release 附件保存。

## 证据边界

本轮只执行代码审查、确定性测试、本机 Android 构建和产物核验，不连接或操作手机。安装后的厂商解码器与具体直播 CDN 表现由用户测试形成设备证据。

# 3.2.0 全平台与功能扩展任务清单

更新时间：2026-09-21

## 当前基线与执行规则

- 源码已注册 **31 个直播站点 + IPTV，共 32 个适配器**。用户列出的 Y Live、AcFun、Picarto、TwitCasting、猫耳、映客、克拉克拉、花椒、OPENREC、TTingLive、小红书、niconico、微博和 IPTV 均已在 `lib/core/sites.dart` 注册；本轮继续新增 SHOWROOM、CHZZK、Kick、17LIVE、LiveMe、TikTok LIVE、YouTube Live、Bigo Live、PandaTV 与 PopkonTV。
- 本轮范围同时包含：42 个已注册直播平台的能力补齐、2 个生命周期归档平台、后续国际/电商/区域平台扩展，以及录制与诊断功能。
- 先连续完成平台和功能源码，每个独立改动提交并同步 GitHub；完整 Analyze、测试、构建和设备验收集中到源码批次结束后执行。
- 新平台按“URL/分享识别 → 元数据/状态 → 媒体候选 → 线路/画质/请求头 → 播放/录制 → 目录/搜索/弹幕 → 应用注册”推进。
- 公开平台注册至少具备有效媒体证据；元数据阶段保留为内部 readiness，不用空地址或陈旧声明创建假入口。

## 参考实现核对

- bililive-go `ef71711`：当前源码注册 20 个站点；战旗仍读取旧 `VideoLevels.streamUrl`，仅作为历史兼容参考；一直播等站点用于比较现行入口。
- DouyinLiveRecorder `add187f`：当前 README/源码覆盖 50+ 平台；用于筛选仍活跃的 URL、请求头和媒体合同，不直接复制 Python 运行时。
- Streamlink 8.5.x：当前维护 YouTube、Bigo、CHZZK、Kick、TwitCasting、niconico、SOOP 等插件；其插件更新记录用于判断平台现行契约与维护活跃度。
- 所有参考实现都需重新核对官网响应、身份字段、直播状态和媒体有效性，再转换为 Dart 原生适配器。

## D. 功能扩展

### 录制与后台任务

- [ ] 录制前快速探测媒体，按候选自动切换并记录切换原因。
- [ ] 批量任务导入/导出、分组、暂停/恢复、并发与失败重试策略。
- [ ] 按开播状态、时间段、最大时长和磁盘空间调度录制。
- [ ] 可选重命名、分段合并、封面/元数据写入和外部命令钩子。
- [ ] Webhook 通知开播、开始录制、线路切换、完成和失败。
- [ ] 后台任务显示真实阶段、最近活动、下一次重试和输出文件。

### 播放器、资料与诊断

- [ ] 播放源预检与快速首帧，失败后保留用户选择并尝试下一候选。
- [ ] 多线路/多画质记忆按平台和房间分层保存。
- [ ] 收藏、历史、稍后看和录制任务支持标签、筛选、批量操作与备份恢复。
- [ ] 跨平台主播别名与重复房间合并。
- [ ] 画中画、音频模式、弹幕和录制状态统一恢复。
- [ ] 平台状态面板和一键脱敏诊断导出。

# B 站网页版视频页 / 直播页 参考拆解，及 VOD 视频站、直播间、红果播放页的同步落点

> 参考对象：`www.bilibili.com/video/BV…` 与 `live.bilibili.com/<room>` 的网页版版式（以用户提供的三张网页截图为准）。
> 目标：B 站视频站（`modules/vod`）按本文对齐；直播间（`modules/live/room`）与红果播放页（`modules/hongguo/pages/hongguo_player_page.dart`）按 B 站视频页/直播页的显示同步。
> 本文是**版式与落点的代码级盘点**，没有运行期目视：未构建、未启动、未对照网页逐像素核对。判定为“已对齐”的项只表示代码里读到了对应结构与数据，不表示真机验收通过。

---

## 0. 判定口径

| 结论 | 含义 |
|---|---|
| 已对齐 | 结构、数据、交互三处都能在代码里找到，且与网页版同一层级 |
| 本轮补 | 缺口明确，落点文件确定，本轮改完 |
| 留待 | 依赖登录态写接口、推送或网页版独有能力，本轮不做 |

“有按钮”不算对齐：按钮必须读到真实数据、有回调、有失败分支。

## 1. B 站网页版视频页

### 1.1 版面分区（自上而下、左主右辅）

| 区域 | 网页版内容 | 行为 |
|---|---|---|
| 播放器 | 16:9 画面、弹幕层、控制条（播放、进度、音量、弹幕开关、清晰度、倍速、网页全屏、全屏） | 播放中控制条淡出，底边留一条细进度线；移动指针唤回；双击全屏 |
| 标题行 | 稿件标题一行 | 长标题省略 |
| 数据行 | 播放量 · 弹幕数 · 发布日期 | 纯文本一行，助手数字缩写（万/亿） |
| 操作行 | 点赞 / 投币 / 收藏 / 分享，分隔线后是稍后再看、下载 | 数字与动作同键；收藏态反转文案 |
| UP 主行 | 头像、昵称、粉丝说明、关注按钮 | 关注态反转 |
| 简介 | 展开/收起的长文本卡片 | 默认折行 |
| 评论区 | 标题「评论 · N」+ 排序页签「最热 / 最新」；每条：头像、昵称、时间、正文、点赞、回复数；底部「加载更多」 | 切排序重读第一页；分页续读 |
| 右侧推荐栏 | 每条：封面+时长角标、标题两行、UP 名、播放量、弹幕量；栏底「换一换」 | 与主栏独立滚动；最多 20 条 |

### 1.2 网页版里对我们不适用的部分

- 顶栏站内导航、搜索框、投稿入口：属于 B 站站点 chrome，不搬。
- 分享面板、稍后再看、关注 UP：需要登录态写接口，留待。
- 「换一换」：推荐接口一次给 40 条，我们只取 20；换批需要再次请求，留待。
- 网页全屏：桌面端窗口化已由 `multiview` 承载，等价能力是全屏与画中画，不新增网页全屏态。

## 2. B 站网页版直播页

| 区域 | 网页版内容 | 行为 |
|---|---|---|
| 播放器 | 直播画面 + 弹幕层 + 控制条（播放、音量、弹幕开关、清晰度、线路、画面比例、全屏） | 与控制条同样的自动隐藏规则 |
| 右侧聊天栏 | 页签「弹幕列表 / SC / 弹幕设置 / 屏蔽」；滚动弹幕流；底部输入框与礼物栏 | 独立滚动，输入栏常驻 |
| 播放器下方信息条 | 主播头像、昵称、房间标题、分区、关注按钮、人气值 | 信息条不随控制条隐藏 |
| 全屏 | 聊天栏转为浮层，可开关 | 桌面端由窗口承载 |

## 3. 三端映射与落点

### 3.1 播放器与浮层

| 项 | VOD 视频站 | 直播间 | 红果播放页 |
|---|---|---|---|
| 浮层控制条自动隐藏 | 已对齐 `vod_video_page.dart:_playerSurface` | 已对齐 `player_surface.dart` | 已对齐 `hongguo_player_page.dart:_playerSurface` |
| 播放中底边细进度线 | 已对齐 `PlayerIdleProgress` | 已对齐 | 已对齐 |
| 指针停在控制条上不隐藏 | 已对齐（栏外套 `MouseRegion`） | 已对齐 | 已对齐 |
| 清晰度/分P/倍速面板 | 已对齐（`_VodPanel`） | 清晰度/线路/画面/弹幕 | 画面/定时/倍速 |
| 双击行为 | 播放/暂停（与网页的双击全屏不同，沿用直播间的既有键位） | 播放/暂停 | 播放/暂停 |

### 3.2 信息区

| B 站区域 | VOD 视频站 | 直播间 | 红果播放页 |
|---|---|---|---|

| 操作行 | 收藏 + 点赞/投币/收藏数；**本轮补**带文字的下载入口 | 关注/分享等 | **本轮补**收藏（本机）+ 下一集 |

## 4. 本轮改动清单

1. **VOD 评论排序**：`VodCommentsState` 增加 `sort`（1 最热 / 2 最新），控制器新增 `setSort`——清空当前页、回到第一页重读；`_CommentsSection` 标题右侧放两段式控件。排序值随请求传给 `BilibiliVodClient.comments(sort:)`（`bilibili_vod_client.dart:620` 已支持）。
2. **VOD 推荐栏弹幕数**：`VodVideo` 增加 `danmakuCount`，列表解析读 `stat.danmaku`（与详情页读的是同一个字段）；`VodVideoRow` 在播放数旁显示弹幕数，沿用 `AudienceFormat` 缩写与 `DsIcons`。
3. **VOD 标题下下载**：操作行加一个带文字的次要按钮「下载视频」，复用 `_startDownload`（解析 `fnval=0` 的混流地址、落盘、进度胶囊、取消都在既有实现里）。
4. **红果观看头**：播放器与选集之间插入：
   - 剧名（标题级文字）；
   - 数据行：`第 N 集 · 共 M 集 · 时长 · 播放 · 评论 · 点赞`（集数取 `HongguoSeriesMeta.episodeCount`，为 0 时退回已读集数；时长优先用播放器回报值，未就绪时用 `HongguoEpisode.durationSeconds`）；
   - 操作行：本机收藏（与剧集页同一份 `hongguoLibraryProvider.toggleFavorite` 与提示文案）、下一集（存在才显示）；
   - 简介两行截断。
5. **直播间不新增结构**：右侧聊天栏（弹幕列表 / SC / 弹幕设置 / 屏蔽 + 输入框）、主播信息条、底边细进度线都已在 `room_page.dart` 与 `player_surface.dart` 中，与网页版同一层级；本文只登记，不改动。

## 5. 留待

| 项 | 卡在哪 |
|---|---|
| 点赞 / 投币 / 收藏写回 B 站 | 需要登录 Cookie 与 `csrf`，现有客户端只读 |
| 关注 UP、稍后再看 | 同上，写接口 |
| 分享 | 需要分享面板与系统剪贴板/外链策略 |
| 评论区发送、点赞、回复展开 | 只读评论链路 |
| 推荐栏「换一换」 | 需要再请求一次相关推荐并去重 |
| 红果播放页的相关作品栏 | 相关作品链路目前只在剧集页（`official/hongguo_related.dart`），播放页未接 |
| 直播礼物栏 | 需要礼物接口与余额，直播间目前无登录态礼物面板 |
| 红果作者卡 | 详情接口不提供作者字段 |

## 6. 验证说明

- 门槛：`dart analyze apps/pure_live/lib packages/live_vod` 无问题；`live_vod` 既有测试不回退。
- 未做：构建、启动、截图对照；红果播放页的数据行在无网络/空详情时的实际观感未验证。
- 已知取舍：评论区页签用 `DsSegmentedControl`（desen_ui 既有控件），不是网页版的下划线小页签——保持与红果评论面板「本集 / 整剧」同一套控件语言。

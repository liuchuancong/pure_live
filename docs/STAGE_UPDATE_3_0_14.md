# Pure Live v3.0.14 Android 播放器稳定性修复

## 交付范围

- 源码版本：`3.0.14+4102`
- 目标：Android `arm64-v8a` Release
- 本轮不合并上游、不构建其他客户端、不操作手机
- 技术审计：[PLAYER_RECOVERY_AUDIT_3_0_14.md](PLAYER_RECOVERY_AUDIT_3_0_14.md)

## 主要修复

1. 为房间、画质、线路与内核切换建立来源代次，隔离旧播放、尺寸和错误回调。
2. 修复同一 URL 软件解码回退提前返回；按视频硬解一次、线路、内核顺序有界恢复。
3. 分离音频/视频解码诊断，以真实解码帧确认播放就绪，并增加原生打开与首帧截止时间。
4. Fijk/BetterPlayer 捕获同步打开失败；内核切换、初始化与小窗清理支持回滚和有界完成。
5. 录制覆盖全部清晰度/CDN 候选，FFmpeg 显示真实脱敏失败类别。
6. 固定并校验 FFmpegKit Dart/原生二进制 profile，防止跨版本缓存混用。

## 验证要求

- 完整质量门禁：构建策略、仓库审计、格式、一次静态分析、全量 Flutter 测试和公开接口探测。
- APK 门禁：包名、`3.0.14+4102`、唯一 `arm64-v8a`、Flutter 资源、翻译、FFmpegKit/SQLite/MediaKit/应用原生库、正式签名和 SHA-256。
- Release 只发布与 `master` 同一提交生成并通过固定证书指纹核验的 APK、构建元数据和校验文件。

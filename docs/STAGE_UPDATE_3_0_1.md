# v3.0.1 Android 竖屏直播适配

- 版本：`3.0.1+4089`
- 本轮目标：Android `arm64-v8a` Release APK
- 其他平台：继续使用 v3.0.0 已发布安装包，本轮不启动对应构建

## 行为设计

1. 以解码后的实际视频宽高识别直播源方向；宽高独立事件先成对合并，再经稳定门确认，切换清晰度和线路不会使用瞬时混合尺寸。
2. 普通手机页默认采用均衡高度，竖屏源获得更大的画面但保留下方弹幕列表；沉浸模式扩大画面，兼容模式固定为原 16:9。
3. 全屏默认跟随稳定源方向；用户可改为跟随系统或始终横屏。Android 大屏、折叠屏和分屏尊重系统的自适应窗口规则。
4. Android 画中画和应用内浮窗使用稳定比例；画中画比例在进入前限制到平台合法范围，进入后不持续改变 Activity 比例。
5. 房间内提供自动、强制竖屏和强制横屏快捷覆盖，可按设置持久化。诊断层可显示原始尺寸、比例和当前策略。

## 验证范围

- 纯 Dart：三样本/500 ms 稳定门、近方形中性区、瞬态画质尺寸、手动覆盖优先级、PiP 极端比例。
- Widget：普通手机页视频增高后仍保留至少 200 px 弹幕列表；原手机/桌面/IPTV 几何回归保持通过。
- 平台边界：紧凑手机可应用方向锁，600dp 以上大屏保持自适应。
- 正式构建：完整质量门禁通过后，只执行 Android arm64-v8a Release 阶段并记录产物、耗时、缓存与峰值资源。

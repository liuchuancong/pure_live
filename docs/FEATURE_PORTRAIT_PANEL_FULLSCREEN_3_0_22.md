# v3.0.22 Android 竖屏下滑全屏实现记录

## 冻结基线与归因

- 维护分支基线：`0159c2e996a7fba9b18b3e72f790315dd3bff041`
- 本轮不合并上游，避免把无关变更带入竖屏交互修复。
- 归因：维护分支的 `PortraitLiveRoomLayout` 只把面板高度夹在最小、中间、最大三个停靠点，结构上没有“完全移出屏幕”的状态；因此弹幕栏无论下滑多少都只能停在最小高度。这是维护分支现有竖屏布局的功能缺口，不是普通直播路径或本轮上游回归。

## 启用边界

专属入口必须同时满足：

1. Android 平台；
2. 播放器稳定分类为竖屏源；
3. 用户已开启竖屏源适配；
4. 用户已开启播放器区域自适应高度；
5. 布局模式不是兼容模式；
6. 当前仍处于普通直播间展示状态。

布局层与控制器层分别检查条件。普通比例直播、临时未稳定的尺寸样本、兼容布局和 Windows 均不显示入口，也不注册该手势。

## 交互状态机

- 面板下拉先消耗当前高度直到最小停靠点，剩余位移才转换为整体向下偏移，使画面在拖动时连续露出。
- 松手时使用自适应阈值：面板高度的 30%，并夹在 72–144 px；或速度不低于 900 px/s 且有效距离不低于 28 px。未达到阈值回到最近停靠点。
- 提交后 180 ms 完成面板退出动画，再进入独立 `portraitFullscreen` 展示状态；挂起标记阻止重复手势创建多个进入请求。
- 进入系统沉浸模式后再次检查稳定竖屏判定和设置。条件已经变化、系统返回抢先发生或展示状态被取消时，立即恢复普通状态、系统栏和方向。
- 竖屏全屏固定竖向。播放器控制条沿用 2 秒自动隐藏；底部“上滑恢复弹幕栏”提示 3 秒后淡出并忽略命中，之后只显示直播画面和画面弹幕。
- 从底部 96 px 手势区上滑 64 px，或快速上甩 24 px，可恢复普通竖屏房间。该手势只在 `portraitFullscreen` 状态接管，其他模式仍使用原亮度/音量手势。

## 退出与兼容

- Android 系统返回、顶部返回、双击退出和底部上滑均回到普通竖屏房间，不销毁播放器和弹幕会话。
- 系统返回在沉浸进入的短暂竞争窗口内也会识别专属状态并执行系统全屏清理。
- 竖屏稳定判定在播放中转为非竖屏时自动退出专属状态；普通横屏全屏、小窗比例和桌面布局未改动。

## 验证范围

- 下滑距离阈值、快速下甩、短拉回弹与重复进入约束。
- 仅移动端稳定竖屏启用；普通直播、关闭适配、关闭自适应高度、兼容模式与桌面全部隔离。
- 底部上滑退出阈值、提示 3 秒淡出、专属全屏状态与系统返回清理。
- 既有竖屏检测、普通直播布局、Android 全屏控件顺序与横屏面板回归。

## 审查发现与处置

1. 上游把 Android、Windows、Linux、macOS、iOS和 Release 输入全部改为默认开启，违反本仓库按需、串行构建规则；合并时保留维护分支的全部默认关闭值。
2. 上游版本、Release URL与 MSIX 版本仍是 2.9.8/2.9.5；保留维护版本 `3.0.0+4088` 和 `wzgrx/pure_live` 更新源。
3. 历史工具函数被绑定到 `HistoryController.to`，未注册 GetX 控制器的单元测试和纯数据路径会失效；恢复为纯函数，并让控制器调用同一实现。
4. 历史上限缺少备份/恢复、边界和导入裁剪；统一限制为 1–500，写入备份，恢复及提取时裁剪，避免一次手势触发数千条网络请求。
5. 历史刷新原为逐条串行请求，删除也存在原地集合修改；刷新复用全局有界并发设置与 12 秒单请求超时，所有结果改为发布新列表，确保速度、Hive 持久化与响应式订阅一致。
6. 新增多画面/新窗口开关对缺失键默认 `false`，导致升级后原有入口消失；缺失键默认保持 `true`，显式关闭仍被保留。
7. 平板导航读取开关时没有响应式订阅；以 `Obx` 包裹入口，使设置立即生效。
8. 英文录制提示使用了与调用方不一致的键且正文仍是中文；改成实际调用键并补齐英文文本。
9. 上游提交含两处尾随空格和设置页缩进错误；合并后统一格式化并由静态门禁拦截。

## 同期直播页回归审查

上一个同步批次的 `eae6c9e7` 把手机普通直播页改成默认关闭的全屏翻转层，导致进入房间只看到视频，顶部以外的画质、线路和弹幕 UI 被隐藏。该改动来自上游，但维护分支此前未设置布局不变量测试，因而进入了错误的 v3.0.0 草稿。

本轮删除该 Shell，恢复稳定的普通页布局：手机同时显示视频、画质/线路和弹幕列表；桌面保留 300–400 px 可见侧栏；IPTV 不保留空面板。新增 Widget 回归锁定三种几何关系，并把该产品不变量写入 `UPSTREAM_REVIEW_POLICY.md`。

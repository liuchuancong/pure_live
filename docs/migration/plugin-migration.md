# 插件迁移

> v1 没有"插件"形态;迁移的对象是 v1 中**插件前身**的配置与数据。

## 对象

| v1 概念 | v2 去处 |
|---|---|
| 站点启用/禁用、排序 | 对应 source 插件 enabled/sort |
| 站点 Cookie/登录态 | auth 保险箱(按 sourceId 映射,不搬明文——重新认证一次) |
| TVBox/IPTV 订阅 URL | data 插件 repository 配置 |
| 自定义源(如有) | JS 插件(lx 兼容层落地后)或 data 插件 |

## 规则

- 插件配置按插件命名空间写入;凭据只映射"该站曾登录"状态,引导一次性重登(安全优先)。
- 未被 v2 首发收录的站点配置保留在"待处理",待对应插件上线后一键启用。

# 设置迁移

## 映射

| v1 设置 | v2 |
|---|---|
| 播放设置(引擎/硬解/超分/默认画质) | settings_repository(播放域令牌) |
| 弹幕设置(速度/透明度/屏蔽词) | danmaku 配置 |
| 外观(主题色/壁纸/字体缩放) | theme + background 配置 |
| 下载/缓存目录 | files/storage 配置 |
| 语言/字体 | l10n / fonts |

## 规则

- 键名映射表驱动(旧键 → 新键 + 转换函数);未知键忽略并记录。
- v1 的"播放内核一键配置"产出(mpv 调优)→ pure_live_media 的应用调优默认值。
- 屏蔽词/自定义排序等用户资产全量平移。

# 映客精确 UID 查询（2026-09-23）

映客适配器原已有按稳定 UID 查询 `live_share_pc` 的元数据路径，但搜索页将整个平台归为未接入。官网现行页面也以“映客号”标识账号（[官网主页](https://inke.com/)）；本批复用项目已验证的详情合同，增加精确 UID 与 `inke.cn` / `inke.com` 官网房间链接查询。映客官网有限精选仍不是全站目录，昵称或关键词搜索仍待接口取证。

## 行为合同

- 仅第一页请求一次精确 UID；官网链接只提取已校验的 `uid`，不把广播 ID 当持久房间身份。无效关键词、分类链接、相似主机和重复 UID 不发请求。
- 搜索调用详情的元数据模式，不查询精选列表或播放地址。真正播放和录制时仍重新取得当前广播 ID 与公开媒体。
- 平台明确的“当前无直播”返回离线房间；搜索卡以 `UID {id}` 显示可识别身份，不虚构主播昵称。仅 HTTP 404 作为空结果，访问失败、服务异常和取消保留原错误语义。
- 搜索能力标为 `roomLookup`，无分页及网页关键词搜索；中英目录说明同步改为精确查询可用、昵称搜索和弹幕待接入。

## 验证与剩余范围

映客 API、应用/搜索、目录迁移、搜索排序与站点注册五文件定向回归 **52/52** 通过；五个改动 Dart 文件定向 Analyze 无诊断；中英翻译 JSON 校验通过。历史目录迁移测试同步按当前第 38 版核对，并用持久化批处理等待异步写入后重开本地数据。

本批尚无当前生产房间的实时查询和 Android/Windows 搜索页操作证据；后续候选集中验证在线/离线卡、进房及返回、有限精选以外的 UID 和播放地址可得性。更多公开目录、昵称搜索、弹幕与长录仍按[平台能力表](PLATFORM_COMPATIBILITY.md)分别推进。

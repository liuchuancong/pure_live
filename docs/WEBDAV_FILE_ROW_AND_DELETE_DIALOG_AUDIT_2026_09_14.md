## 文件行与删除合同

- 文件/目录名称最多两行并使用省略号，完整名称通过 `Tooltip` 可读；
- 修改时间最多一行，避免长时间文本继续推高动作入口；
- 文件行使用三行布局预算，在 3.0 倍文字下仍保留可命中的尾部菜单；
- 空白 `name` 使用清理尾斜杠后的 `path` 末段显示，两者都缺失时使用本地化占位；
- 中文确认正文为“确定要从 WebDAV 删除‘目标名称’吗”，英文正文使用同一 `{name}` 参数；
- 删除弹窗使用页面 `BuildContext`、16/20 窗口边距、420 宽正文、可滚动内容、向下动作溢出及 48×48 最小动作尺寸；
- 取消、系统返回和确认分别返回 `false`、`false`、`true`，只关闭当前确认路由；
- 控制器在弹窗出现前占用文件动作事务，继续阻止重复确认、上传或恢复；结果返回后仍核对服务代次和目录路径，服务切换或目录变化不会提交旧删除。

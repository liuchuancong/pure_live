# 花椒公开推荐范围关键词筛选

2026-09-23，在既有花椒精确号/官方主播主页查询之外，接入当前公开推荐视频直播的昵称与标题筛选。数据来自适配器已使用的 `feed/getLives4H5` 原生游标，不宣称全站主播索引，也不构造网页搜索入口。

## 范围与实现

- 每次关键词查询最多顺序读取 3 页当前公开推荐（请求各自使用服务端 `offset`），按稳定主播 UID 去重后本地分页。命中足够填满目标页或服务端结束时提前停止。当前推荐里没有的主播仍可用精确花椒号或官方主播主页查询。
- 数字身份优先走精确查询；无效纯数字、房间直播链接、其他网站链接和控制字符不转成关键词。精确查询只返回第一页，关键词结果按查询页分页；取消令牌贯穿目录请求和页间检查。
- 搜索范围提示、目录提示和平台能力表同步标明“三页公开推荐、非全站搜索”。`current_heat` 仍仅作热度，不当作并发在线人数；筛选不拉取播放媒体。

## 验证

- 定向 Flutter/API/搜索页与生命周期回归 **149/149**。新增测试覆盖第二、三页才出现的匹配、重复 UID 去重、分页、三页上限、精确身份与错误链接分流，以及首请求取消后不前进游标。
- 显式只读探针 `PURELIVE_HUAJIAO_SEARCH_PROBE=1` 运行 `tool/probes/huajiao_recommendation_search_probe_test.dart`：2026-09-23 当前公开第一页 2 条，从第一页动态挑选昵称，经注册适配器筛选命中 1 条，耗时 1334 ms；不取媒体、不做原生播放或录制。该实时样本只证明当时的入口可达，不代表三页持续稳定或双端客户端通过。
- 全库 Analyze、Android/Windows 当前候选 GUI、花椒弹幕及播放/短录/长录验收留在 3.2.0 集中门禁。

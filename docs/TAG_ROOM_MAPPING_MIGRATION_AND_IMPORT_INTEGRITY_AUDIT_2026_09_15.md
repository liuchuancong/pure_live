1. 旧房间号映射会复制到所有同房间号、平台身份有效的收藏房间。
2. 目标平台已有映射时先保留其顺序，再追加旧键中尚未出现的有效标签；迁移不丢任一有效分配。
3. 映射键和标签 ID 去除外围空白；空键、空 ID、未知 ID、重复 ID 及归一化后的空列表不进入运行态或持久化。
4. 多个原始键规范为同一键时按输入顺序合并，而非后项覆盖前项。
5. 备份导入的空/重复标签 ID 在发布前修复；映射中的旧重复 ID 继续指向排序后保留该 ID 的第一项。
6. 仅替换标签集合时，旧映射只保留新集合仍存在的 ID；完全失去有效 ID 的房间键被删除。
7. 映射保存与导出使用独立列表快照，后续内存修改不反向改变已生成的备份或待写值。

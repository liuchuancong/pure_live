# v3.0.5 Android 有效画面识别与竖屏三模式增强

- 版本：`3.0.5+4093`
- 本轮目标：Android `arm64-v8a` Release APK
- 其他平台：继续使用既有发布包，本轮不启动对应构建
- 上游状态：本轮按要求不合并上游，基于维护分支 `f77123d2` 开发

## 根因

播放器报告的是解码后的**编码画布**。部分抖音等竖屏直播实际把 9:16 节目嵌入 16:9 画布，
左右带黑边；只读 `dw/dh` 会稳定得到 16:9。此前强制竖屏只改变外层画框，原始 16:9 纹理仍被
直接填充到 9:16，因此普通页出现拉伸，横屏与小窗复用同一播放器后也同步失真。

## 统一识别系统

1. 保留同一解码事件的 `dw/dh`、旋转归一化、三次样本/500 ms 稳定门作为第一层证据。
2. 新增有效画面分析：新直播会话最多采集两张 192 px 宽截图，分析对称黑边、暗像素比例、
   边缘方差、中心活跃度，并要求两次高置信结果一致。
3. 编码比例与有效节目比例分别保存；裁剪视口先去掉黑边，再由唯一 `BoxFit` 层缩放，避免拉伸。
4. 房间、线路和清晰度切换使用 geometry generation 隔离旧 Timer；按 `platform:roomId` 保存
   最多 96 个、4 小时的进程内稳定快照，重进房间先显示临时快照，再由新证据校正。
5. 暗场、转场、非对称遮罩、低置信结果和不支持截图的播放器继续使用解码元数据；手动房间覆盖
   保持最高呈现优先级。

## 三种竖屏呈现

- **普通竖屏页**：视频使用完整画布，画质与弹幕成为收起/中间/展开三档互动面板；拖动把手与
  弹幕列表滚动手势隔离。均衡模式默认中档，沉浸模式默认收起，兼容模式保持旧布局。
- **横屏全屏**：竖屏纹理保持可信比例居中，两侧使用缓存封面的模糊暗化背景；控制层继续覆盖
  整个屏幕，不复制播放器、不增加持续视频解码。
- **系统/应用小窗**：稳定竖屏源跟随有效节目比例形成竖长窗口；Android PiP 入场保留源矩形和
  无缝缩放，后续识别结果改变时更新活动 PiP 参数。

## 普通直播保护

- 只有稳定 portrait、竖屏适配开关开启且处于手机断点时进入新普通页布局。
- 横屏、方形、未知直播继续原页面、全屏与 16:9 小窗合同。
- 全帧分析只运行两次且离开渲染循环，不启用持续 cropdetect，不增加稳态 CPU/GPU 任务。

# Windows11 安装 MSIX 提示证书不受信任 完整解决教程
Windows 11 默认仅信任微软商店签名应用，手动编译的 MSIX 安装包会提示 **证书不受信任/无法安装**，按照以下步骤手动导入信任证书即可正常安装。

## 操作步骤
1. 右键下载好的 **MSIX 安装包**，选择 **属性**
2. 切换到 **数字签名** 选项卡
3. 选中签名列表，点击 **详细信息**
4. 在弹窗中点击 **查看证书**
5. 点击 **安装证书**，启动证书导入向导
6. 存储位置选择：**本地计算机**，点击下一步
7. 选择 **将所有的证书都放入下列存储**
8. 点击 **浏览**，选择 **受信任的人** 证书存储目录
9. 确认目录后点击 **确定**
10. 持续点击 **下一步**，最后点击 **完成** 导入证书
11. 关闭所有弹窗，**重新双击 MSIX 安装包** 即可正常安装

## 补充说明
- 该问题仅出现在 **自行编译、非微软商店分发** 的 MSIX 安装包
- 证书只需导入一次，后续新版本安装无需重复操作
- 导入后系统永久信任该开发者证书，无安全风险（开源自用软件）

# 工具箱直播间链接预检与抖音作品边界（2026-09-23）

## 复现

工具箱进入时会读取剪贴板，并用 `LiveUrlTool.containsSupportedLink` 决定是否自动填入房间号/取流输入。旧预检只要命中平台根域名就返回真：Bilibili 空首页、斗鱼搜索、Twitch 目录、Picarto 搜索、TwitCasting 旧电影、快手搜索等六个非房间链接均可触发误填。另一个相邻问题是 `www.douyin.com/video/{id}` 被按尾部数字映射成直播房间，和抖音搜索页尾号一样把作品/关键词混成房间身份。新增测试先得到稳定红灯。

## 修订

预检现在复用 `WebSearchRoomParser` 的可同步房间合同；重定向短链和既有旧域名别名仍用与实际 `parseLiveUrl` 一致的有限路径规则。抖音 `www.douyin.com/{数字房间号}` 继续回流，而 `/video/{id}`、`/search/{keyword}` 不再映射为直播；直播短链和 `webcast.amemv.com/.../reflow/{room}` 保持原路径。对旧版接受的 Bilibili 数字根路径、斗鱼别名和 CC 频道根路径补了预检一致性断言，避免修复误填时损坏有效输入。

## 验证与边界

六文件集中回归 **207/207**，三文件定向 Analyze 无诊断；本批不操作手机。测试覆盖预检布尔值、手动解析、网页跳转识别及相邻三个站点适配器的确定性夹具。实际系统剪贴板弹窗与双端界面仍并入候选原生验收。

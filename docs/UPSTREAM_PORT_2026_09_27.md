### 局域网同步的安全改造

上游实现在同步页打开期间，同一网络内任何设备都能读取全部设置（含各平台登录 Cookie）并覆盖本机设置：没有配对、没有确认，并返回 `Access-Control-Allow-Origin: *`。本仓库版本：

- 每次启动服务生成 6 位配对码，显示在本机并写入二维码；所有设置请求必须携带，否则 403（常量时间比较）。
- 被读取或被覆盖的设备弹窗确认，拒绝返回 403。
- 去掉 CORS 头。
- 账号 Cookie 仅在打开“同步账号 Cookie”时发送；`exportAllSettings` 保持默认不含 Cookie（上游改为默认包含，会让所有本地/WebDAV 备份带上 Cookie）。
- Android 17 启动前申请“本地网络”权限。
- mDNS 类型由占位的 `_my-service._tcp` 改为 `_purelive-sync._tcp`。
- 修复上游问题：停止后无法再启动；`host:port` 形式无法解析；任意文字被当作主机名；4 个文案缺翻译；应答对话框会连同页面一起关闭。

真机（REDMI K90，Android 17）核对：无配对码或配对码错误 → 403 且不弹窗；配对码正确 → 手机弹窗，拒绝 → 403 且页面保留，允许 → 返回不含 Cookie 的设置。

## 未移植

| 上游改动 | 原因 |
| --- | --- |
| 更新渠道改为 `liuchuancong`、版本号 3.1.5 | 两边 APK 签名不同，无法覆盖安装 |
| 删除 `StableVideoLayer` / `displayVideoLayer`、进入录制中心前的等待 | Windows 纹理崩溃与 Android 黑屏的防护，上游无验证记录 |
| Windows 画面心跳改由解码回调驱动 | 与本仓库的卡顿检测方式冲突，需单独实测 |
| 平板侧边栏不可滚动 | 横屏或矮窗口时底部导航项无法点击 |
| 录制列表按创建时间排序 | 回退了录制显示时间逻辑 |
| 删除 5 个测试 | 降低覆盖 |
| YY 取流 `cid` 与 `sid` 相同 | 子频道房间会取错；本仓库版本探针可取到媒体 |
| 图片下载忽略 HTTPS 证书错误 | 全局降低安全性 |
| 字体存入下载目录 | Android 默认下载目录不同，已下载字体会显示为未下载 |
| Microsoft YaHei 回退逻辑 | 只处理上游自身写入的状态 |
| 每次根组件重建后 `Get.changeTheme` | 多一次全局重建，无对应问题 |
| 多画面改用 `LivePlayBackScope` | 普通状态下会跳过“先卸载纹理再退出”的安全退出流程 |
| Firebase 启动前联网探测 | 本仓库初始化本就不阻塞启动，探测只会多等最多 10 秒 |
| 用户目录分页与角色过滤重写 | 仅管理员可见，且移除了现有测试依赖的接口 |
| 弹幕设置页的本地互动开关 | 已有独立设置页；该处 `Get.find` 可能找不到控制器 |
| 标题栏外包 `Overlay` | 本仓库标题栏已不使用 Tooltip |
| Anime4K 滤镜列表 | 未接入播放，也没有着色器文件 |

# v2.1.6 Android 播放状态修复

v2.1.6 针对 Android 音频/视频模式切换与后台音频生命周期进行专项修复，源码版本为 `2.1.6+54`。

## 灰白播放器根因与修复

- 灰白区域是 Flutter 发布模式在组件构建异常时显示的 `ErrorWidget`，不是直播线路返回的白色视频。
- 旧实现先销毁 media_kit/MediaCodec，再从组件树移除旧视频控制器；新控制器又以异步方式开始播放，连续切换时会造成销毁、重建和迟到回调交叉。
- 新实现先卸载旧视频组件并等待一帧，再销毁底层播放器；所有模式请求通过串行队列执行，积压操作只应用最后一次目标状态。
- 播放器组件在一次构建中固定使用同一个播放器快照，并防御历史画面适配索引越界，关闭外层检查通过后底层引用又被异步清空的窗口。
- 新播放器初始化可等待，`hardDispose` 会作废旧播放会话，避免迟到的播放结果重新绑定旧 Surface。

## issue #750

- 音频模式现在是独立的后台播放条件，不依赖通用“后台播放”开关。
- 退到桌面或锁屏时，音频模式保持媒体会话、前台服务与 CPU/Wi-Fi 保活；通知栏播放状态继续和播放器同步。
- 普通视频且后台播放关闭时仍按原设计暂停；睡眠会话与显式后台播放开关保持原行为。

## 构建目标

优先构建正式包名 `com.mystyle.purelive` 的 `arm64-v8a` APK，并在 Android 16 / ColorOS 真机覆盖安装回归。其他平台源码不受 Android 生命周期策略影响。

# 花椒精确 UID 与主播主页查询（2026-09-23）

## 来源与生产取证

- 官网[主播主页示例](https://h.huajiao.com/site/profile_268933114.html)以稳定花椒号标识主播，不以当前场次 ID 作为持久身份。原有适配器的 `Web/UserInfo/full` 接口已用于收藏刷新；本批复用同一身份和开播状态读取链。
- 2026-09-23 匿名探针读取两份真实主播资料：`base.uid` 与请求 UID 一致，`living=0` 表示当前未开播。不存在的 16 位 UID 返回 `errno=0`、`base=[]`、`living=0`；仅把这一窄响应识别为未找到，不把其他结构漂移当空结果。
- 用户资料接口不返回已核实的当前并发人数；搜索卡片的观看值保持未知。目录里的 `current_heat` 仍独立作为热度，不写入并发人数。

## 源码合同

- 原生搜索只接受精确花椒号或已核验的官方主播主页链接，首页/昵称/关键词/广播链接不作为此入口的精确 UID；分享链接中广播 ID→UID 的现有异步解析保持独立。
- 查询只读主播资料，不读取媒体或当前直播流；返回在线/离线身份，点入房间时仍经原有详情链重新核对当前广播。页码大于 1 直接结束；请求取消传至网络层。
- `base=[]` 且 `living=0` 映射为未找到；畸形资料、UID 不一致、网络错误仍保持错误。搜索能力文案中英双语说明精确范围，不宣称昵称搜索。

## 验证边界

五文件定向回归 **142/142**、翻译合同 **1/1**、定向 Analyze 无诊断。覆盖原生搜索入口、官方链接、未开播身份、未知观看值、未找到哨兵、畸形响应、请求取消和搜索页操作。Android/Windows 当前候选早于本批源码，真实输入、点入与返回并入后续集中验收。

# 视频设置 ASMR 定时路由与保存事务审计（2026-09-14）

## 范围与结论

本批在 09-11 已完成的 ASMR 定时弹窗布局、紧凑时长格式和输入控制器生命周期基础上，继续复核视频设置页入口、路由所有权、异步定时服务配置和偏好持久化。基线为 `5fd241ca1bd20af13c5dbf7ef17b8ca0bc4815e7`，实现提交为 `1ac4919b541e279cea13301e976ae0e718c13e1d`。

旧入口每次调用都直接创建 `showDialog`，没有页面级门禁或当前路由检查；同一个已捕获回调连续触发会稳定叠加两个 `AlertDialog`。保存又先写 `asmrSleepMinutes`，再等待 `LiveAudioService.configureSleepTimer`：底层更新失败时持久偏好已经变更，弹窗仍停留且没有失败说明；等待期间保存、取消、预设和输入仍可重复操作，可能并发提交多次。非法输入只显示瞬时 Toast，不在对应输入框留下可修正状态。

`1ac4919b` 让页面在创建根 Navigator 路由前同步持有单次事务，并检查页面挂载和当前路由；取消、遮罩、系统返回、保存完成或页面退出后统一释放。弹窗只接收初始分钟数和页面提供的异步保存回调，不再直接读取或改写设置服务。保存期间输入、预设、取消和保存同时置灰，系统返回由 `PopScope` 暂停；服务配置成功且页面/控制器仍有效后才持久化分钟数并关闭弹窗，失败则保留原值和当前输入，显示双语行内错误后允许重试。

既有响应式布局继续保留十个预设、完整滚动面、16/20 窗口边距、360 px 正文上限和至少 48×48 的取消/保存动作。320×480、3.0 倍英文文字下弹窗仍在窗口内，末项、输入和两个动作均可滚动到达。

## 交互与状态合同

1. ASMR 时长入口一次只拥有一条弹窗路由；快速重复触发不叠加路由。
2. 页面已销毁或被其他路由覆盖时，旧入口不再创建弹窗；事务结束后入口可再次使用。
3. 1～525600 之外的输入不调用定时服务、不写偏好，并在输入框显示范围错误；继续编辑即清除错误。
4. 每次保存只调用一次定时服务；等待期间预设、输入、取消、保存和系统返回均不产生第二项工作。
5. 定时服务完成前持久值保持原样；服务失败保留弹窗、草稿和旧值，并提供可重试的双语反馈。
6. 只有服务成功且页面、路由和设置控制器仍有效时才提交分钟数；随后由根 Navigator 精确关闭所属弹窗。
7. 09-11 已验证的聚焦输入生命周期、十个预设可达性和分钟/小时/天紧凑单位继续成立。

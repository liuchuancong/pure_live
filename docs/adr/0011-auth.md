# ADR 0011:认证模型(Auth Model)

- 状态:已接受(2026-10-08)

## 背景

多平台登录(Cookie/扫码/OAuth)各自为政;凭据安全与过期处理在 v1 分散。

## 决策

账号 Provider 化(Account: providerId/accountId/profile/session/status);AuthManager → AccountStore → 源内 AuthProvider;支持 Cookie/Token/OAuth/QR/Device/Anonymous;统一 `auth.expired` 事件,刷新责任在 Provider;凭据只存系统安全存储(secure_storage),对 JS 插件仅暴露布尔级登录态。见 [../services/auth.md](../services/auth.md)、[../security/credential-storage.md](../security/credential-storage.md)。

## 后果

- 正:会话生命周期统一;登出清理完整(v1 斗鱼会话残留教训);凭据面收窄。
- 负:各站登录细节仍须各自实现(在源内),auth 只保证流程与存储一致。

# ADR 0008:插件安全

- 状态:已接受(2026-10-08)

## 背景

开放第三方插件 = 引入不可信代码;安全边界必须在设计期确定。

## 决策

四道防线:安装管线(签名/哈希/兼容/权限评审)→ 运行时(JS 沙箱 flutter_js + 未声明权限即拒)→ 数据隔离(命名空间/凭据不外泄/备份不含凭据代码)→ 可审计(全事件诊断+一键禁用)。权限最小化 I8;JS 无裸 HTTP 只走 PluginNetwork。详见 [../security/](../security/)。

## 后果

- 正:生态可开放而不牺牲主体安全;用户可理解可控制。
- 负:JS 能力受限(复杂协议走 Native);授权流程增加安装摩擦(可接受)。

# 网页搜索房间确认与导航归属（2026-09-23）

## 可复现缺口

网页搜索在识别直播链接后弹出应用内打开确认。旧控制器只用页面生命周期代次拦截晚到的确认：弹窗打开时，网页若跳到搜索页，点击确认仍打开旧房间；若跳到另一直播间，旧确认会优先打开前一房间，吞掉新的目标。两个时序回归在修复前均失败。

## 修订与证据

控制器现在记录最近观察到的稳定房间身份。无房间导航立即清空待处理目标；确认返回后仅处理仍与当前导航一致的目标，较新的目标仍在同一个串行弹窗队列中继续处理。关闭页面的既有生命周期代次保护不变。

网页搜索生命周期与链接解析联合 **27/27**，两文件定向 Analyze 无诊断。原生 WebView 的实际导航与弹窗交互留到当前候选双端验收；本批未操作手机或构建安装包。

- 每项使用全行 `SimpleDialogOption`，最小高度为 48；Radio 后的文本放入 `Expanded` 并允许自动换行，窄屏和大字号不再扩张自然宽度。
- `RadioGroup` 继续表达当前值和键盘/语义选择；Radio、文字及行内空白均提交同一候选值。
- 所有内置选择回调使用弹窗自身 `BuildContext` 关闭所属路由；系统返回和遮罩关闭继续返回 `null`。

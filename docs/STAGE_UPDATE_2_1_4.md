# v2.1.4 阶段更新说明

v2.1.4 是一次接口稳定性、Windows 高刷新率和全平台交付更新，源码版本为 `2.1.4+52`，上游同步到 `liuchuancong/pure_live@5d3e526a`。

## 平台接口

- Bilibili 热门从持续触发 `-352` 的旧分区接口迁移到当前匿名推荐接口，并保留有界重试、独立回退与响应结构检查。
- 房间、头像和分区封面统一补齐站点请求头与稳定缓存键，减少偶发拒绝、重复下载和缓存膨胀。
- SOOP Live 同步当前播放地址获取逻辑，并兼容 `sooplive.com` 与 `sooplive.co.kr` 链接。
- 平台接口探测覆盖 26 条分类、推荐、搜索、房间、弹幕和播放令牌链路。

## Windows 性能

- 原生 Runner 读取当前窗口所在显示器的分辨率、当前刷新率和同分辨率最高刷新率；跨屏或显示模式变化后自动刷新。
- Windows 跟随 Flutter 和系统垂直同步，不在应用内强制修改系统显示模式。
- 次级页面使用轻量前进转场，桌面滚动统一夹持物理模型，并修复收藏页重复注册平台监听器。
- 封面使用稳定磁盘缓存键，头像取消列表批量淡入动画，减少高刷新率滚动中的下载、重建与合成开销。

## 数据与安装

- Windows EXE 继续允许选择其他磁盘；设置、关注、历史、IPTV、录制与缓存统一保存在安装目录 `AppData`。
- 升级前保留回滚备份，并兼容旧 List 与新 JSON 配置结构以及历史安装目录迁移。
- Android 使用正式包名 `com.mystyle.purelive` 和仓库持久签名，覆盖安装不会生成并存版。

## 构建矩阵

| 平台 | 产物 |
| --- | --- |
| Android | arm64-v8a 正式签名 APK |
| Windows | x64 EXE 安装器、便携 ZIP |
| Linux | x64 便携 tar.gz |
| macOS | universal ZIP、DMG |
| iOS | arm64 未签名设备 `.app` 归档 |

Android 与 Windows 优先在本机执行质量门禁和构建；Linux 与 Apple 平台使用显式阶段标签补建，普通提交不会自动消耗 Actions 配额。

# Pure Live v3.0.16 阶段更新

- 版本：`3.0.16+4104`
- 冻结上游：`liuchuancong/pure_live@9b1c0a6ee0c469e1363fbb214ad7abf26f775a27`
- 目标产物：Android `arm64-v8a` Release APK
- 证据边界：源码审查、确定性测试、静态分析、本机构建、APK 内容与签名核验；本轮不使用手机或 ADB。

## 本轮修复范围

1. 播放器生命周期统一由协调器决定，来源事件按代次隔离，播放器内核切换采用成功后提交、失败回滚的事务路径。
2. Android 原生 Surface 跟随 `SurfaceProducer` 替换合同，稳定视频图层在覆盖场景保持挂载；帧探测只用于强提示冲突，不对普通直播常驻运行。
3. 斗鱼完整媒体 URL 拼接修复；斗鱼、虎牙按单条 CDN 生成录制地址。
4. 录制清晰度与线路改为惰性游标，任务 schema 4 保存安全重试位置，签名 URL 保持纯运行时。
5. FFmpeg 输入、格式、网络、命令、输出错误保持独立分类；录制中心卡片顺序、阶段信息、码率和动画开销修正。
6. 完成上游 `e696bb79`、`9b1c0a6e` 三方审计，舍弃上游版本/依赖降级与发布策略覆盖。

## 验证矩阵

- 播放器：事件早于 open、重定向 URL、无 path、内核失败回滚、音频/视频恢复、Android Surface 替换、稳定纹理和竖横屏几何。
- 录制平台：哔哩哔哩、斗鱼、虎牙、抖音、快手、网易 CC、Twitch、SOOP、YY、IPTV。
- 录制状态：首次启动、线路轮换、清晰度后备、短时签名刷新、自动重连、手动停止、旧任务迁移、输出目录保护和录制中心展示。
- 交付：完整仓库审计、完整 Flutter 回归、公开接口探测、Android arm64 APK 资产/ABI/原生库/版本/证书/SHA-256 核验。

## 回滚

- 生命周期、来源/内核、Android Surface/几何、录制解析和录制 UI 均为独立提交，可按子系统回滚。
- 平台外部接口漂移只替换对应适配器；不通过反复重建播放器或清空用户配置掩盖接口错误。
- v3.0.15 保留为上一个正式回滚点。

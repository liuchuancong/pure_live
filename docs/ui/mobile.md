# Mobile(手机形态)

> Android 手机 / iOS 的体验层约定。

- **手势**:播放器单击出控制层、双击侧边快进快退、竖屏全屏顶底栏让位刘海(v1 SafeArea 方案延续)、返回两段语义(先退全屏再退页面,PlayerBackScope 模式)。
- **系统**:状态栏/导航栏沉浸、音频焦点(audio_session:拔耳机暂停/来电让路)、后台播放策略(音频模式继续、视频模式暂停)、画中画 PiP。
- **权限**:通知(开播提醒,远期)、后台(下载/录制)、存储(导入导出)按需申请。
- **性能**:高刷适配(AdaptiveRefreshRateScope 延续)、低端机背景降级。

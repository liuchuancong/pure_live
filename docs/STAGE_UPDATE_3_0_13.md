# Pure Live v3.0.13 Android 录制修复

## 交付范围

- 源码版本：`3.0.13+4101`
- 目标：Android `arm64-v8a` Release
- 本轮不合并上游、不构建其他客户端、不操作手机
- 详细技术审计：[RECORDING_AUDIT_3_0_13.md](RECORDING_AUDIT_3_0_13.md)

## 主要修复

1. Android FFmpegKit 在应用服务完成注册后立即非阻塞预热，录制入口等待同一幂等初始化，修复首次点击录制时的原生 I/O 失败窗口。
2. 十个平台全部实现严格录制房间解析：接口失败进入有界重试，只有明确下播或封禁才停止，并保留画质/线路所需完整字段。
3. FFmpegKit 使用原始参数向量，签名 URL、HTTP 请求头与含空格目录不再经过命令字符串二次解析。
4. 立即录制与监控录制分离，移除同一次点击产生的重复启动意图。
5. 任务页显示脱敏后的失败阶段与摘要，区分房间、画质、线路、网络、FFmpeg、合并和调度错误。
6. Android minSdk 对齐 FFmpegKit 当前依赖要求 API 26。

## 验证要求

- 完整质量门禁：构建策略、仓库审计、格式、一次静态分析、全量 Flutter 测试、公开接口探测。
- APK 门禁：包名、`3.0.13+4101`、唯一 `arm64-v8a`、Flutter 资源、翻译、FFmpegKit/SQLite/MediaKit/应用原生库、正式签名与 SHA-256。
- Release 只发布与 `master` 同一提交生成并通过固定证书指纹核验的 APK、构建元数据和校验文件。

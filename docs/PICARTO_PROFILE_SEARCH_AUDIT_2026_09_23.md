# Picarto 官网主播档案搜索（2026-09-23）

## 接口证据

- [官网搜索页](https://picarto.tv/search?q=artist)的当前脚本发起 `GET https://ptvintern.picarto.tv/api/search`，参数为 `first=20&page=1&q=artist&type=searchProfiles&tag_search=false`。响应包含 `searchProfiles.data`，每行有频道 `id/name/online/avatar/follower_count`，搜索结果同时包含直播中和未开播档案。
- 同一关键词的第 2 页仍返回 20 行，但这次响应的 `count=0`，而第 1 页 `count=2270`。因此 `count` 不参与继续翻页或结束判断；搜索页用返回行与重复页保护来推进。这些数字只是当时匿名响应快照。
- 搜索档案没有当前同时在线人数、直播标题或媒体流字段。本接入只将 `follower_count` 放到粉丝字段，将观看与当前在线人数留空；进入房间后仍用原有详情链读取最新状态及播放地址。搜索阶段不读取 HLS。

## 实现与范围

- `PicartoApi.searchProfiles()` 逐页请求官网档案，校验请求范围、频道身份、开播布尔值和字段形状，保留请求取消；不缓存跨关键词/跨页面的状态。
- `PicartoSite` 接入应用原生可取消搜索；能力说明从网页入口更新为“直播中及部分未开播”，官网网页搜索按钮仍可使用。结果是主播档案关键词匹配，不承诺直播标题全文搜索。
- 公开目录的成人过滤和分类分页保持原有合同；档案搜索展示头像、频道名、粉丝与状态，不把粉丝数写成观众数。远端弹幕仍按既有状态显示。

## 验证边界

定向回归覆盖官方参数、第二页 `count=0` 但仍有结果、在线/离线身份、粉丝口径、输入与响应畸形、取消和搜索页按钮。Android/Windows 新候选的实际输入、离线筛选、点入播放及返回仍并入集中原生验收。

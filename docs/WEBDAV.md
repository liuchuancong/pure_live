# WebDAV 配置与排查

Pure Live 可将配置备份上传到用户选择的 WebDAV 服务，也可从 WebDAV 下载备份并同步到本地。服务套餐、流量和页面入口可能调整，请以服务商当期说明为准。

## 配置字段

在 Pure Live 中进入“设置 → 备份与还原 → WebDAV”，新增配置并填写：

| 字段 | 内容 |
| --- | --- |
| 配置名称 | 仅用于本地识别，例如 `家庭备份` |
| 服务地址 | 服务商给出的完整 HTTPS WebDAV 地址，通常以 `/` 结尾 |
| 用户名 | WebDAV 账号；部分服务要求注册邮箱 |
| 密码 | 独立的应用密码或访问令牌，通常不是网页登录密码 |

建议为 Pure Live 单独创建应用密码，并使用独立子目录，例如：

```text
https://WEBDAV_HOST/dav/pure-live/
```

保存后先刷新目录，再上传一份测试备份并执行下载回读。确认测试文件内容正常后，再用于日常同步。

## 坚果云示例

坚果云常用配置为：

| 字段 | 示例 |
| --- | --- |
| 服务地址 | `https://dav.jianguoyun.com/dav/` |
| 用户名 | 坚果云注册邮箱 |
| 密码 | 网页端“安全选项 → 第三方应用管理”生成的应用密码 |

应用密码通常只在创建时展示一次。遗失后删除旧凭据并重新创建即可。仓库中的引导图片位于 [`assets/webdav/`](../assets/webdav/)，应用内也提供同一入口的图文提示。

## 数据保护

- 为每个客户端使用独立应用密码，停用设备时单独撤销。
- WebDAV 地址仅使用 HTTPS。
- 备份格式 v3 默认剔除平台 Cookie 和 WebDAV 凭据，但备份仍可能包含收藏、历史、直播源及其他个人配置，应按敏感文件保管。
- 不要把真实 WebDAV 地址、用户名、密码或备份文件提交到 Issue、Pull Request 和 Git 历史。

## 常见问题

### 账号或密码错误

1. 核对服务商要求的是用户名、注册邮箱还是专用账号。
2. 使用应用密码或访问令牌，不混用网页登录密码。
3. 确认应用密码仍有效，并具备目标目录的读写权限。

### 浏览器直接打开地址显示错误

WebDAV 是面向客户端的协议端点，浏览器页面错误不等同于客户端连接失败。以 Pure Live 的目录刷新、上传和下载回读结果为准。

### 上传或下载超时

1. 核对 HTTPS 地址、端口、路径和末尾斜杠。
2. 查看服务商状态、配额、单文件大小和速率限制。
3. 临时排除系统代理、DNS 或防火墙规则对该域名的影响。
4. 使用同一凭据在另一 WebDAV 客户端执行最小文件读写，区分服务端与应用端问题。

### 子目录不存在

先在服务商网页端或其他 WebDAV 客户端创建目录，再把完整目录地址填入 Pure Live。部分服务不会自动创建 URL 中尚不存在的多级目录。

### 重置授权

在服务商的第三方应用管理页面撤销对应应用密码，然后为 Pure Live 创建新凭据并更新本地配置。

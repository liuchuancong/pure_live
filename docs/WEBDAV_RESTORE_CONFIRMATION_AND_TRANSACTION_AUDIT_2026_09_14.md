## 范围与结论

本轮以 `ff22596b` 为基线，代码修订提交为 `79d8965f`。范围限 WebDAV 远端备份“同步到本地”入口在覆盖本机设置前的用户决策、目标身份、窄窗口大字号布局，以及确认等待、读取和本地恢复之间的事务边界；未连接真实 WebDAV 服务器，未构建 Windows 或 Android 候选，未执行原生 Windows GUI、ADB 或设备操作，Astra Light 使用 **0 次**。

旧入口在用户选择菜单后立即调用远端 `readFile`，解析 JSON 后直接执行 `restoreAllSettings`。界面没有说明将使用哪个文件，也没有在覆盖本机全部设置前取得明确决定。旧控制器只在远端读取完成后核对服务身份，目录已变化时仍可能把旧目录文件写入本机设置。

`79d8965f` 将恢复确认交给 WebDAV 页面：弹窗标题和确认动作均为“恢复备份”，正文显示完整目标名称，并明确说明将覆盖本机设置、应用备份内全部配置。确认与删除共用页面所属的响应式弹窗结构；删除继续使用危险色，恢复使用普通主动作样式。控制器通过必需的确认回调等待页面结果，在任何远端读取或本地设置变更前完成决定，并在确认后、读取后和本地恢复后共同核对服务代次与目录路径。

A1-05 获得新的确定性 Widget 与控制器证据；真实服务器和 Android/Windows 当前候选仍需后续验收，因此状态保持 `RUN`。

## 恢复确认与事务合同

- 菜单选中“同步到本地”后先占用单次文件动作事务，再等待页面确认；等待期间恢复菜单和上传入口保持禁用；
- 中文正文为“确定要使用‘目标名称’恢复并覆盖本机设置吗？恢复将应用备份中的全部配置”，英文使用同一 `{name}` 参数；
- 弹窗使用页面 `BuildContext`、16/20 窗口边距、420 宽正文、可滚动内容、向下动作溢出及 48×48 最小动作尺寸；
- 长名称在 320×480、3.0 倍文字下完整出现在滚动正文中，取消和恢复动作均可命中；
- 取消、系统返回和点按遮罩都产生否定结果，在远端读取前结束事务，本机设置保持原值；
- 确认后才读取选中文件并调用本地恢复；恢复完成前继续阻止上传、重复恢复和删除；
- 服务替换、页面关闭或目录路径变化会使旧事务失效；确认后或读取后到达的旧结果不会进入本地设置；
- JSON 解码、类型转换或恢复失败仍释放忙碌状态并保留明确错误反馈，随后可重新操作。
